# NIIRS AutoScanner: Burp Suite Extension

**Тема НИРС:** Разработка инструмента автоматизированного поиска технических и логических уязвимостей веб-приложений в среде Burp Suite.  
**Автор:** Студент 5 курса кафедры ИБ МГТУ им. Н.Э. Баумана.  
**Текущий статус:** ✅ Этап 1 завершен (Базовый алгоритм поиска логических уязвимостей).

---

## 📋 Описание проекта

Проект представляет собой кастомное расширение для Burp Suite, написанное на языке **Kotlin** с использованием современного **Montoya API**. Инструмент предназначен для автоматизации рутинных задач пентеста:
1. Автоматический поиск логических уязвимостей (в первую очередь, IDOR) с помощью кастомных эвристических алгоритмов.
2. Оркестрация внешних инструментов (Nuclei, sqlmap) для поиска технических уязвимостей (SQLi, XSS, SSRF).

## ⚙️ Реализованный функционал (Этап 1)

На текущем этапе плагин реализует продвинутый алгоритм детекции IDOR при подмене сессионных данных. Ключевые особенности:

- **Селективный перехват трафика:** Анализ только исходящих запросов из инструмента Proxy, что исключает шум от фоновых задач Burp Suite.
- **Умная фильтрация (Allowlist):** Проверка только целевых эндпоинтов (`/api/`, `/rest/`, `/profile`, `/basket`, `/admin`). Статические ресурсы (`.css`, `.png`, `.woff2`) и WebSocket-соединения (`socket.io`) игнорируются для предотвращения ложных срабатываний (False Positives).
- **Механизм обхода кэша (Cache-Bypass):** Перед повторной отправкой запроса алгоритм принудительно удаляет заголовки `If-None-Match` и `If-Modified-Since`, добавляя `Cache-Control: no-cache`. Это гарантирует получение честного ответа `200 OK` вместо `304 Not Modified`.
- **Эвристический анализ (Diffing):** Сравнение оригинального и модифицированного ответов по трем метрикам:
    1. Совпадение HTTP-статусов (Baseline Check: анализ начинается только при исходном статусе `2xx`).
    2. Совпадение длины тела ответа (в байтах).
    3. Расстояние Левенштейна (оценка семантической близости текстового содержимого).
- **Потокобезопасность:** Использование `CopyOnWriteArrayList` для хранения состояния предотвращает ошибки конкурентного доступа в многопоточной среде Burp.
