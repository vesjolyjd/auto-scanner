# Burp AutoScanner: Burp Suite Extension

**Тема НИРС:** Разработка инструмента автоматизированного поиска технических и логических уязвимостей веб-приложений в среде Burp Suite.  
**Автор:** Студент 5 курса кафедры ИБ МГТУ им. Н.Э. Баумана.  
**Текущий статус:** Активная разработка. (Реализованы эвристические алгоритмы IDOR, Vertical Privilege Escalation, Info Disclosure, оркестрация Nuclei, кастомный UI Dashboard с динамической конфигурацией. Ведётся работа над повышением точности детекции и снижением False Positives).

---

## 📋 Описание проекта

Проект представляет собой кастомное расширение для Burp Suite, написанное на языке **Kotlin** с использованием современного **Montoya API**. Инструмент автоматизирует рутинные задачи пентеста, объединяя три подхода:
1. **Кастомный эвристический анализ** для поиска логических уязвимостей (IDOR/BOLA, Vertical Privilege Escalation), которые часто пропускают стандартные сканеры.
2. **Детекцию утечек информации (Info Disclosure)** через анализ ответов сервера на предмет стек-трейсов, ошибок валидации и внутренних путей.
3. **Оркестрацию внешних инструментов** (Nuclei) для автоматического поиска технических уязвимостей (SQLi, XSS, SSRF) прямо из интерфейса Burp.

## ⚙️ Реализованный функционал

### 1. Поиск логических уязвимостей (IDOR / BOLA)
- **Глубокая мутация запросов:** Автоматическое извлечение и подмена идентификаторов в 4-х векторах:
  - HTTP Cookie (`token`, `session`, `jwt`, `authorization`)
  - Path Parameters (например, `/users/5` → `/users/1`)
  - Query Parameters (фильтрация только "опасных" параметров: `id`, `user_id`, `tenant_id` и др.)
  - JSON Body (безопасная модификация AST-дерева через библиотеку Jackson).
- **Вертикальная эскалация привилегий (Vertical Privilege Escalation):** Автоматическая генерация запросов с подменой полей ролей (`role`, `admin`, `privilege`, `is_admin`) на значения `admin`, `true`, `1`, `root`, `superuser`.
- **Механизм обхода кэша (Cache-Bypass):** Принудительное удаление заголовков `If-None-Match` и добавление `Cache-Control: no-cache` для предотвращения ложных срабатываний на ответах `304 Not Modified`.
- **Smart Diffing & Baseline Check:** Анализ начинается только при успешном исходном ответе (`2xx`). Сравнение модифицированного ответа по трём метрикам: статус-код, длина тела и расстояние Левенштейна.
- **Детектор "Ложных 200 OK":** Фильтрация ответов, содержащих ключевые слова ошибок (`unauthorized`, `forbidden`, `error`, `rate limit`), даже если сервер вернул статус `200`.
- **Асинхронное выполнение:** Все проверки запускаются в фоновых потоках (`kotlin.concurrent.thread`), не блокируя интерфейс Burp Suite и работу браузера.

### 2. Детекция утечек информации (Info Disclosure)
- **Универсальный детектор ошибок:** Анализ ответов сервера на предмет ключевых слов, характерных для Java (`java.lang.`, `at com.`), PHP (`Fatal error`, `PDOException`), Python (`Traceback`), .NET (`System.Data`), Node.js (`stacktrace`, `at /`).
- **Проверка исходных ответов:** Детекция утечек даже в базовых запросах со статусом 4xx/5xx (стек-трейсы, ошибки валидации, внутренние пути).
- **Трёхуровневая классификация:** `SAFE` → `ERROR_GENERIC` (игнорируется) → `INFO_LEAK` (добавляется в Dashboard).

### 3. Оркестрация внешних средств (Nuclei)
- **Автоматический триггер:** При обнаружении запросов с точками входа для инъекций (Query, JSON, POST-метод) плагин автоматически сохраняет Raw HTTP во временный файл.
- **ProcessBuilder Integration:** Асинхронный запуск `nuclei -l <file> -json -timeout 30` в изолированном окружении.
- **NDJSON Парсинг:** Чтение и парсинг потока вывода Nuclei через Jackson с фильтрацией информационных сообщений и выводом только реальных находок (Severity: Medium/High/Critical) в лог Burp и UI.

### 4. Архитектура и надёжность
- **Централизованная конфигурация (`ScannerConfig`):** Все эвристики, списки ключевых слов и пейлоады вынесены в единый объект. Списки реализованы как `MutableSet` для поддержки динамического изменения через UI.
- **Умная фильтрация (Allowlist):** Анализ только целевых API-эндпоинтов (`/api/`, `/rest/`, `/admin` и др.). Статика и публичные роуты (`/public/`, `/health`, `/swagger`) игнорируются для минимизации False Positives.
- **Потокобезопасность:** Использование `CopyOnWriteArrayList` для хранения состояния перехваченных запросов предотвращает `ConcurrentModificationException` в многопоточной среде Burp.
- **Дедупликация находок:** Автоматическое объединение находок по URL и типу с накоплением деталей (векторов атаки) в одной строке таблицы.

### 5. Кастомный UI Dashboard
- **Таблица находок** с цветовой индикацией Severity (Critical/High/Medium/Low), сортировкой по клику на заголовок, живым поиском и фильтрацией по типу/критичности.
- **Умный рендерер Details:** Многострочное отображение с автоматическим сокращением (>3 строк → "… и ещё N"), tooltip с полным текстом при наведении.
- **Динамическое изменение ширины:** Двойной клик по заголовку колонки Details автоматически подстраивает ширину под самый длинный текст.
- **Контекстное меню:** Open in Repeater, Copy URL, Copy Details, Delete.
- **Экспорт в JSON:** Сохранение всех находок в форматированный JSON-файл для отчётов.
- **Интерактивные настройки:** Кнопка "⚙️ Настройки" открывает диалоговое окно с 7 вкладками для редактирования всех списков эвристик без перекомпиляции плагина.

## 🏗️ Технический стек

- **Язык:** Kotlin 1.9+ (JVM Target 17/21)
- **API:** PortSwigger Montoya API
- **Сборка:** Gradle + плагин `com.gradleup.shadow` (для создания fat-jar)
- **Парсинг JSON:** Jackson (`jackson-module-databind`)
- **UI:** Java Swing (JTable, JDialog, JTabbedPane)
- **Внешние зависимости:** ProjectDiscovery Nuclei

## 🚀 Установка и запуск

### 1. Требования
- JDK 17 или JDK 21.
- Burp Suite (версия 2024.1 и выше, поддерживающая Montoya API).
- Установленный и доступный в системе `nuclei` (проверка: `nuclei -version`).

### 2. Сборка проекта
В корневой папке проекта выполните:
```bash
./gradlew shadowJar
```
Готовый файл будет расположен по пути: build/libs/burp-plugin.jar.
### 3. Загрузка в Burp Suite
1. Откройте Burp Suite → вкладка **Extensions**.
2. Нажмите **Add** (или Install).
3. Extension Type: **Java**.
4. Extension File: выберите скомпилированный `burp-plugin.jar`.
5. Перейдите во вкладку **Output** внутри описания расширения для просмотра логов.
