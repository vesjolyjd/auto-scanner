## 📋 Описание проекта

Проект представляет собой кастомное расширение для Burp Suite, написанное на языке **Kotlin** с использованием современного **Montoya API**. Инструмент автоматизирует рутинные задачи пентеста, объединяя три мощных подхода в одном интерфейсе:
1. **Глубокий эвристический анализ** для поиска логических уязвимостей (IDOR/BOLA, Vertical Privilege Escalation), которые часто пропускают стандартные активные сканеры.
2. **Детекцию утечек информации (Info Disclosure)** через интеллектуальный анализ ответов сервера на предмет стек-трейсов, ошибок валидации и раскрытия внутренних путей.
3. **Оркестрацию внешних инструментов** (Nuclei) для автоматического поиска технических уязвимостей (SQLi, XSS, SSRF) прямо из интерфейса Burp без ручного экспорта запросов.

## ⚡ Ключевые возможности

### 🔍 Эвристический анализ IDOR / BOLA
- **Data Exposure:** Обнаружение несанкционированного чтения данных через анализ рефлексии идентификаторов и чувствительных полей в ответе.
- **Data Modification:** Детекция успешных операций изменения или удаления чужих объектов (POST/PUT/DELETE) по отсутствию признаков отказа в ответе `2xx`.

### 🧬 Многовекторная мутация запросов
Автоматическое извлечение и подмена параметров в 5 независимых векторах:
1. **HTTP Cookie:** Подмена токенов аутентификации.
2. **Path Parameters:** Поддержка числовых ID, UUID и префиксных идентификаторов (например, `user_123`).
3. **Query Parameters:** Умная фильтрация только потенциально опасных параметров (`id`, `user_id`, `tenant_id`).
4. **JSON Body:** Безопасная модификация AST-дерева через библиотеку Jackson с сохранением исходных типов данных.
5. **HTTP Headers:** Проверка обхода контроля доступа через заголовки (`X-User-Id`, `X-Original-URL`, `X-Forwarded-For` и др.).

### 🛡️ Интеллектуальная фильтрация False Positives
- Игнорирование известных публичных эндпоинтов и артефактов фронтенда (`NaN`, `undefined`, Socket.IO polling).
- Умная обработка ответов `401/403`: парсинг JSON для отличия стандартных сообщений об ошибке от реальных стек-трейсов (Info Disclosure).
- Алгоритм Левенштейна с предварительной очисткой динамических полей (`timestamp`, `csrf`, `token`) для точной оценки семантического различия ответов.

### 🖥️ Кастомный UI Dashboard (Java Swing)
- Потокобезопасная таблица находок с цветовой индикацией критичности (Severity).
- Агрегированный прогресс-бар с защитой от race conditions.
- Умный рендеринг деталей: компактное отображение с предпросмотром успешных векторов и автоматическим скрытием избыточной информации.
- Экспорт результатов в структурированный JSON (с опциональным режимом подробного аудита `full_audit_log.json`).

### 🔄 Оркестрация внешних средств
- Автоматический триггер сканирования через **ProjectDiscovery Nuclei** для запросов с точками входа, с парсингом NDJSON-вывода и интеграцией находок в общий Dashboard.

## 🏗️ Технологический стек

- **Язык:** Kotlin 1.9+ (JVM Target 17/21)
- **API:** PortSwigger Montoya API

## 🚀 Сборка и установка

### 1. Требования
- JDK 17 или JDK 21.
- Burp Suite (версия 2024.1 и выше, с поддержкой Montoya API).
- Установленный в системе `nuclei` (опционально, для расширенного сканирования).

### 2. Сборка проекта
В корневой папке проекта выполните:
```bash
./gradlew shadowJar
```
Готовый файл будет расположен по пути: build/libs/burp-plugin.jar.

### 3. Загрузка в Burp Suite
1. Откройте Burp Suite → вкладка **Extensions**.
2. Нажмите **Add** (или **Install**).
3. Extension Type: **Java**.
4. Extension File: выберите скомпилированный `burp-plugin.jar`.
5. Перейдите во вновь появившуюся вкладку **AutoScanner Dashboard** для управления сканером.

## ⚙️ Настройка и использование

Нажмите кнопку **⚙️ Настройки** в Dashboard для конфигурации эвристик без перекомпиляции:
- **Маркеры Auth:** Строки для фильтрации авторизованного трафика.
- **Чувствительные поля:** Ключевые слова для поиска в JSON и Query-параметрах.
- **Жертвы IDOR:** Значения, на которые подменяются исходные идентификаторы.
- **Внешние инструменты:** Абсолютный путь к исполняемому файлу Nuclei и переключатель режима подробного аудита (`Verbose Export`).
